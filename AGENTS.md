# AGENTS.md

Indoor 3D navigation with Wi-Fi fingerprint positioning. Vanilla JS + Three.js frontend with Preact UI; a shared Hono app that runs both locally (Node) and on Cloudflare Workers.

## Commands

- `pnpm dev` — Vite dev server. This is the main dev loop; it serves the app and map assets (`/map.obj`, `/map.mtl`, `/map.navmesh.bin`) from `public/`.
- `pnpm build:navmesh` — offline navmesh generation: parses `public/map.obj` (scale 0.5, rotation 0), runs recast `threeToSoloNavMesh`, writes `public/map.navmesh.bin` + prints stats. Must be re-run when `map.obj` changes.
- `pnpm build` — `vite build --mode production` → `dist/`.
- `pnpm start` — `node --experimental-strip-types server.ts`; Hono serves `dist/` on port 3000. Requires `pnpm build` first.
- `pnpm check` — `tsgo --project tsconfig.json && tsgo --project src/tsconfig.json` (native TS compiler preview, `@typescript/native-preview`). Exits 0. Root tsconfig checks the node/server side (`types: ["node"]`), `src/tsconfig.json` checks the browser app (Preact JSX + `types: ["vite/client"]`). Deps: `@types/node`, `@types/three` must stay installed.
- `pnpm cap:sync` — `capacitor sync` (copies `dist/` + plugins into `android/`). `pnpm cap:sync:android` = build + sync; `pnpm cap:open:android` opens Android Studio.
- No test or lint scripts exist. `.oxlintrc.json` exists but oxlint is not installed and no script runs it.

## Architecture

- `src/App.tsx` — the single app entry (imported from `index.html`): Three.js scene, map loading, floor clipping, pathfinding, pick/nav/wifi logic, fingerprint collector AND the Preact UI. Selects `scanPathfinder` vs `navMeshPathfinder` via `settings.useNavMesh` (settings panel checkbox, needs reload). At the end it mounts itself (`render(<App />, #solid-root)`) and binds DOM refs via `getElementById`.
- UI (Preact 10.29, all in `src/App.tsx`): the `App` component renders the entire DOM chrome declaratively — menus/dialogs/settings/floor slider/instruction panel. Styling uses **CSS** (`src/App.css`); no inline style objects or CSS-in-JS. Shared UI state is `@preact/signals` signals (`instructionItems`, panel/toggle visibility, floor slider) — read via `.value`, set via `.value = x`. DOM refs are obtained by `document.getElementById()` in `bindUiRefs()` after mount into module `let`s — keep IDs in sync or dialogs come up null. UI-strong logic (e.g. floor slider → `switchFloorClipIndex`) lives in the component handlers. `main.js`/`src/ui/` no longer exist.
- Pathfinding: `src/pathFinder.js` (abstract base `PathFinder extends THREE.EventDispatcher`), `src/scanBasedAStar.js` (`ScanBasedPathfinder`, GPU-scan A*), `src/navMeshPathfinder.js` (`NavMeshPathfinder`, imports `/map.navmesh.bin` via recast `importNavMesh` + `NavMeshQuery.computePath`). Both return `Vector3[]|null`; warmUp is a no-op for navmesh.
- `scripts/generateNavMesh.ts` — offline navmesh generation (`pnpm build:navmesh`). Uses scale 0.5 / rotation 0 to match `loadMap()`. NOTE: `walkableRadius` is the agent radius (~3), NOT the old scan `SCAN_RADIUS` (=20, a scan-camera half-extent); radius 20 erodes away all corridors. `walkableClimb=10` connects all 4 floors.
- `app.ts` — shared Hono app. Imported by both `server.ts` (local, `./app.ts`) and `worker.ts` (Cloudflare, `./app.js` — the `.js` extension is required by wrangler). Applies hardcoded basic-auth (`user` / `changeme`), so API routes 401 without it.
- `worker.ts` — Cloudflare Worker entry; `wrangler.toml` binds `dist/` via `ASSETS`.
- Map data: `public/map.obj` + `public/map.mtl` (3D model), `public/map.navmesh.bin` (generated), `src/map.mapMeta.js` (floor elevations), `src/mapDefinition.d.ts` (types).
- Wi-Fi fingerprint positioning (Android only): `src/fingerprint.d.ts` (types), `src/wifiScanner.js` (abstract `WifiScanner` + `CodextWifiScanner` via `@codext/capacitor-wifi`'s `scanWifi()` — natively returns `{wifis:[{bssid, ssid, level}]}`; `MockWifiScanner` for PC, `resolveDefaultScanner` picks by `window.Capacitor.getPlatform() === "android"` or `window.mockWifiScanner` duck-typing), `src/wifiLocator.js` (`WifiLocator extends THREE.EventDispatcher`, weighted KNN over `public/fingerprints.json`, `FINGERPRINT_URL`, `KNN_K=5`, `MISSING_RSSI=-100`). Fingerprint cells are `{x, y, z, macs:{bssid:rssi}}` (absolute map coordinates, not per-floor tags — so stairwells crossing floors can be represented continuously; the estimate is a 3D weighted average, no discrete floor vote).
- Collector lives in `src/App.tsx` (settings panel → 调试选项): picks a map position, averages 3 mock/plugin scans into a `fingerprintDefinition` cell, stores via `@54145a/storage2`'s `WebStorageItemStorage` (reactive proxy under `localStorage["fingerprintCells"]`, shape `{cells:[...]}`, mutations auto-persist debounced — keep the `cells` array reference, clear with `length = 0`), exports as a downloadable `fingerprints.json` to place in `public/`. Settings use the same lib (`new WebStorageItemStorage("settings", localStorage).data`).
- Android shell: `capacitor.config.ts` (appId `com.example.indoornav`, webDir `dist`) + `android/` (generated, `npx cap add android`). WiFi scanning uses `@codext/capacitor-wifi` (its `scanWifi()` returns BSSID + RSSI out of the box — no `pnpm patch` needed; unlike `@capgo/capacitor-wifi` which lacks BSSID in `getAvailableNetworks()` and calls removed `jcenter()`). Release signing reads `android/keystore.properties` (gitignored) — `./gradlew assembleRelease` produces a signed APK.
- Deps: `recast-navigation` + `@recast-navigation/{core,generators,wasm,three}` (wasm port of Recast/Detour). `vite.config.ts` opts `recast-navigation` out of `optimizeDeps` and adds `@preact/preset-vite` (JSX). Browser bundle includes the wasm (~700KB) — the app is deployed on Cloudflare Workers which requires paid WASM support.
- `index.html` is the real app (just `<div id="solid-root">` + the script tags; all chrome and styles are in `src/App.tsx`); `connect.html`/`connect.js` is an unfinished USB test page (connect.js is empty).

## Gotchas

- pnpm is the package manager and `pnpm-lock.yaml` is gitignored.
- `@keupoz/strict-queryselector` is a pnpm `link:` override to sibling repo `../strict-queryselector` — that package lives outside this repo.
- Node executes TS source directly via `--experimental-strip-types`, so server-side imports use `.ts` extensions; `tsgo`/`pnpm check` is check-only and never emits.
- Both tsconfigs use `module: esnext` + `moduleResolution: bundler` + `skipLibCheck: true` + `noEmit: true`. Don't switch back to `nodenext`: `@recast-navigation/core`'s `dist/index.d.ts` re-exports extensionless relative paths (`export * from './serdes'`), which `nodenext` can't resolve, silently dropping the whole chain to an empty module (TS2305 on every named import). `@types/three`/`@types/node` provide real types so dependency JS isn't deeply checked.
- Both tsconfigs set `maxNodeModuleJsDepth: 0` — required, don't remove. `@types/node`'s `process.d.ts` imports bare `string_decoder`; once `string_decoder` actually exists in `node_modules` (pulled in transitively via `@capacitor/cli → native-run → through2 → readable-stream`), bundler resolution binds it to the real JS file instead of the ambient `@types/node` declaration, and tsgo would check that JS (hundreds of TS7006/TS2683). With `maxNodeModuleJsDepth: 0` the real JS is skipped; the ambient declaration covers the types.
- `src/tsconfig.json` types are `["vite/client"]` (no `@types/node` — src is browser-only; the old shared jsconfig with `node` types caused `lib.dom` vs `@types/node` global conflicts). `worker.ts` pulls `@cloudflare/workers-types` via a `/// <reference>` line, keeping root `types: ["node"]`.
- `capacitor.config.ts` needs the `typescript` package (devDep) for the Capacitor CLI to load it; keep `appId` dash-free Java-package form. Changing `appId` requires deleting `android/` and re-running `npx cap add android` (Capacitor 8 has no `remove` command).
- The android Gradle wrapper is pinned to 9.3.1 (Capacitor's default 8.14.3 can't run on the system Java 25: "Unsupported class file major version 69"). Works with AGP 8.13. If `gradle-wrapper.properties` is ever regenerated by Capacitor, restore the 9.x URL or builds fail under Java 25.
- `dev.ts` spawns `vite` + `server.ts` together; the Hono dev-server plugin in `vite.config.ts` is intentionally commented out.
- Preact UI: `src/tsconfig.json` sets `jsx: "react-jsx"` + `jsxImportSource: "preact"` (tsgo type-checks `.tsx`, @preact/preset-vite compiles). Note tsgo does NOT honor JSDoc annotations inside `.tsx` files — the whole app is typed with TS annotations. App styles use **CSS** (`src/App.css`); `index.html` is style-free.
- `eruda` debug console auto-loads only on Android user agents.
- Active work is on the `wip` branch (remote `origin/wip`).
